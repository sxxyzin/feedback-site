# 01. 선생님이 과제를 만들고 과제 현황을 확인한다

Status: open
Type: task

## 내용

선생님이 아이디와 비밀번호로 로그인한 뒤 새 과제를 만들거나 이전 과제를 다시 사용하고, 과제 목록에서 현황을 확인한다.

## 완료 기준

- 브라우저에서 선생님 로그인 후 과제 목록 화면이 보인다.
- 새 과제의 제목·설명·마감일을 입력해 저장할 수 있다.
- 저장한 과제에 제목, 제출 인원, 미피드백 글 수, 마감일이 보인다.
- 이전 과제를 다시 사용하면 제목·설명이 반영된 새 과제가 과제 목록에 보인다.
- 다시 사용한 새 과제에는 이전 과제의 제출 글과 피드백이 보이지 않는다.
- 브라우저를 새로고침해도 저장한 과제와 현황이 보인다.
