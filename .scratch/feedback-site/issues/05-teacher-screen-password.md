# 05. 선생님 화면을 관리자 비밀번호로 잠근다

Status: open
Type: task

## 내용

선생님 화면은 학생 글과 선생님만 보는 내용이 있는 관리자 화면이다. 화면을 열기 전에 관리자 비밀번호를 입력하게 해 학생이 비밀번호 없이 선생님 화면의 내용을 볼 수 없게 한다. 실습용 관리자 비밀번호는 `teacher-demo`로 한다.

## 완료 기준

- 브라우저에서 선생님 화면을 열려고 하면 관리자 비밀번호 입력 칸과 화면을 여는 동작이 보인다.
- 브라우저에서 관리자 비밀번호를 입력하기 전에는 학생 이름, 학생 글, 제출 시간, 피드백 입력 칸 등 선생님만 보는 내용이 하나도 보이지 않는다.
- 브라우저에서 잘못된 비밀번호를 입력하면 오류 메시지가 보이고 관리자 비밀번호 입력 화면에 그대로 머문다.
- 브라우저에서 `teacher-demo`를 입력하면 선생님 과제 목록 화면이 보인다.
- 브라우저에서 학생 계정으로 로그인한 상태로 선생님 화면을 열어도 관리자 비밀번호를 입력하기 전에는 선생님 화면의 내용이 보이지 않는다.
