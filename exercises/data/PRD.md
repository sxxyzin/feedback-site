# PRD

## 1. 문제

수업이 끝난 뒤 학생이 무엇을 이해했는지 선생님이 빠르게 확인하기 어렵다. 학생은 이해한 내용을 자기 말로 제출하고, 선생님은 그 글을 읽고 피드백해야 하지만 이를 과제별로 모아 보고 관리할 화면이 필요하다.

## 2. 대상

대학교 화학 열역학 챕터 3 「엔트로피」 수업의 학생과 선생님이 사용한다. 학생과 선생님이 볼 수 있는 기록이 다르므로 화면을 나누며, 학생은 자기 기록만 보고 선생님은 전체 학생의 기록을 본다.

## 3. 핵심 장면

1. 선생님이 과제를 만들거나 이전 과제를 다시 사용하고 마감일을 정하면, 선생님 화면에 과제 목록·제출 인원·미피드백 글 수·마감일이 보인다.
2. 학생이 선생님이 만든 아이디와 비밀번호로 로그인해 자기 과제를 열고 자유롭게 글을 제출하거나 마감 전 수정하면, 학생 화면에 자기 과제의 제목·설명·마감일과 자기 글이 보인다.
3. 선생님이 미피드백 글을 열면, 학생 이름·제출한 글·제출 시간·피드백 입력 칸이 보인다.
4. 학생이 자기 과제의 피드백을 확인하면, 자기 글과 선생님 피드백이 보인다.

## 4. 만들지 않을 것

- 학생이 다른 학생의 글이나 피드백을 보는 화면
- 다른 학생의 기록을 모아 보는 학생 화면
- 이메일·문자 등 별도 알림
- 학생 글의 최소 글자 수 제한
- 학생의 이모지 반응이나 답글 기능
- 선생님이 학생의 피드백 읽음 여부를 확인하는 기능
- 점수·등급을 매기는 기능
- 학부모 화면
- 실시간 채팅 기능
