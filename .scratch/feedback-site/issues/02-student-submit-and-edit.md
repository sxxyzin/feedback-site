# 02. 학생이 자기 과제를 열고 글을 제출·수정한다

Status: open
Type: task

## 내용

학생이 아이디와 비밀번호로 로그인해 자기 과제를 확인하고 글을 제출하거나 마감 전에 수정한다.

## 완료 기준

- 브라우저에서 학생 로그인 후 자기 과제 목록만 보인다.
- 과제를 열면 제목·설명·마감일과 자기 글 입력 영역이 보인다.
- 글을 제출하면 과제 화면에 제출한 자기 글이 보인다.
- 마감 전 다시 과제를 열면 기존 자기 글을 수정할 수 있다.
- 마감 후에는 제출·수정 동작을 할 수 없다.
- 학생 화면에 다른 학생의 글이나 기록이 보이지 않는다.
