# PRD: 오늘 내가 이해한 것 (중2 과학 피드백 사이트)

> 「PRD」를 끝내지 못했다면 이 파일을 내 폴더에 `PRD.md`라는 이름으로 복사해서 씁니다.

## 문제

과학 수업이 끝나면 학생이 무엇을 이해했고 무엇이 헷갈렸는지 선생님이 알기 어렵습니다. 학습지를 걷어도 피드백을 돌려줄 시간이 없고, 학생은 "어려웠다"는 말을 선생님께 직접 하기 어렵습니다.

## 누가 쓰나

| 사용자 | 하고 싶은 것 |
|---|---|
| 학생 (중학교 2학년) | 오늘 이해한 내용을 내 말로 쓰고, 어려웠던 점을 부담 없이 알리고, 선생님 피드백을 받는다 |
| 선생님 (과학 교사 1명) | 과제를 올리고, 학생 글을 읽고 짧게 피드백하고, 누가 아직 안 읽었는지 안다 |

## 핵심 장면 4개

1. 선생님이 과제를 만들고 마감일을 정한다. 이전 과제도 다시 사용할 수 있다.
2. 학생이 아이디와 비밀번호로 들어와 자기 과제를 확인하고, 마감 전까지 자유롭게 글을 제출하거나 수정한다.
3. 선생님이 전체 학생의 글을 읽고, 아직 피드백하지 않은 글을 먼저 확인한 뒤 글로 피드백한다.
4. 학생이 자기 글과 자신에게 온 피드백을 확인한다.

## 화면

| 화면 | 보이는 것 | 보이면 안 되는 것 |
|---|---|---|
| 학생 | 자기 과제 목록, 상태, 마감일, 자기 글, 자기에게 온 피드백 | 다른 학생의 글과 다른 학생에게 온 피드백 |
| 선생님 | 과제 목록, 제출 인원, 미피드백 글 수, 마감일, 모든 학생 글, 어려웠던 점, 학생 이름, 제출 시간, 피드백 입력 칸 | (없음) |

학생 화면과 선생님 화면은 분리한다. 학생 화면은 로그인한 학생의 기록만 보여 주고, 선생님 화면은 전체 학생의 기록을 보여 준다.

## 만들지 않을 것

- 다른 학생에게 글이나 피드백 공개하기
- 학생이 다른 학생의 기록을 모아 보는 화면
- 이메일·문자 등 별도 알림
- 이모지 반응과 학생 답글 기능
- 학생이 피드백을 읽었는지 확인하는 기능
- 학생 글의 최소 글자 수 검사
- 점수·등급 매기기 (이 사이트는 평가가 아니라 소통용이다)
- AI로 피드백을 자동 작성하거나 다듬기
- 학생의 자유 가입과 실명 인증 (학생 계정은 선생님이 만든다)
- 학부모 화면
- 채팅처럼 실시간으로 주고받는 기능

## 성공의 모습

수업 다음 날 선생님이 화면을 열었을 때, 어떤 과제에 아직 피드백하지 않은 글이 남아 있는지 확인하고 학생 글에 피드백할 수 있다.
