# feedback-site Spec

## 1. 문서 정보

- 기능 이름(feature-slug): `feedback-site`
- 근거 문서: [PRD.md](../../exercises/data/PRD.md)
- 대상 수업: 대학교 화학 열역학 챕터 3 「엔트로피」
- 문서 언어: 한국어

## 2. 목표

수업이 끝난 뒤 학생이 이해한 내용을 자기 말로 제출하고, 선생님이 과제별 제출 현황과 학생 글을 모아 보며 피드백할 수 있게 한다. 학생은 자기 과제와 자기 글·피드백만 본다.

## 3. 범위와 고정 결정

- 화면은 `index.html` 하나로 만든다.
- 로그인 화면, 선생님 화면, 학생 화면 등 모든 화면은 `index.html` 안에서 현재 화면을 바꾸어 보여 준다.
- 데이터는 브라우저 `localStorage`에 저장한다.
- 데이터베이스나 서버 저장소는 사용하지 않는다.
- 테스트 도구나 자동화 테스트는 사용하지 않는다. 동작 확인은 브라우저에서 사람이 직접 화면을 확인하는 방식으로 한다.
- 학생 글에는 최소 글자 수 제한을 두지 않는다.

## 4. 사용자와 접근 범위

### 선생님

- 선생님이 만든 아이디와 비밀번호로 로그인한다.
- 선생님 화면은 관리자 화면이므로, 화면을 열기 전에 관리자 비밀번호를 입력한다.
- 실습용 관리자 비밀번호는 `teacher-demo`로 한다.
- 관리자 비밀번호를 입력하기 전에는 학생 글과 선생님만 보는 내용을 하나도 표시하지 않는다.
- 모든 과제와 모든 학생의 제출 글·제출 시간을 볼 수 있다.
- 과제를 새로 만들거나 이전 과제를 다시 사용한다.
- 학생의 글에 피드백을 작성한다.

### 학생

- 선생님이 만든 아이디와 비밀번호로 로그인한다.
- 자기 과제 목록과 자기 과제의 제목·설명·마감일을 본다.
- 자기 글을 제출하고 마감 전에는 수정한다.
- 자기 글과 선생님 피드백을 본다.
- 다른 학생의 글·피드백이나 전체 학생 기록은 볼 수 없다.

계정 생성·수정·삭제 화면은 만들지 않는다. 로그인에 필요한 사용자 정보는 `localStorage`에 저장된 사용자 데이터로 확인한다.

## 5. 화면 구성

### 5.1 로그인 화면

- 아이디 입력 칸
- 비밀번호 입력 칸
- 로그인 버튼
- 아이디 또는 비밀번호가 일치하지 않으면 로그인하지 않고 오류 메시지를 보여 준다.
- 로그인 성공 시 사용자 역할에 맞는 화면으로 전환한다.

### 5.2 선생님 과제 목록 화면

로그인한 선생님에게 과제 목록을 보여 준다. 각 과제에는 다음 정보를 표시한다.

- 과제 제목
- 제출 인원
- 미피드백 글 수
- 마감일

또한 다음 동작을 제공한다.

- 새 과제 만들기 화면으로 이동
- 기존 과제를 다시 사용하기 위한 선택 화면으로 이동
- 과제를 선택해 해당 과제의 제출 글과 피드백 화면으로 이동

제출 인원은 해당 과제에 글을 제출한 학생 수로 계산한다. 미피드백 글 수는 제출 글 중 선생님 피드백이 아직 없는 글의 수로 계산한다.

### 5.3 선생님 과제 만들기·다시 사용하기 화면

#### 새 과제 만들기

- 과제 제목 입력
- 과제 설명 입력
- 마감일 입력
- 과제 저장

저장한 과제는 선생님 과제 목록에 보이며, 처음에는 제출 인원과 미피드백 글 수가 0이다.

#### 이전 과제 다시 사용하기

- 이전 과제 목록에서 하나를 선택한다.
- 선택한 과제의 제목과 설명을 바탕으로 새 과제를 만든다.
- 새 과제의 마감일을 정한다.
- 저장하면 새 과제로 등록한다.
- 다시 사용해 만든 새 과제에는 이전 과제의 제출 글과 피드백을 복사하지 않는다.

### 5.4 선생님 제출 글·피드백 화면

선택한 과제의 학생 제출 글을 열어 다음 정보를 보여 준다.

- 학생 이름
- 제출한 글
- 제출 시간
- 피드백 입력 칸
- 피드백 저장 동작

피드백을 저장하면 해당 제출 글이 피드백 완료 상태가 되고, 과제 목록의 미피드백 글 수에 반영한다.

### 5.5 학생 과제 목록 화면

로그인한 학생의 과제 목록을 보여 준다. 학생은 자기 과제만 열 수 있다.

### 5.6 학생 과제 화면

선택한 과제의 다음 정보를 보여 준다.

- 과제 제목
- 과제 설명
- 마감일
- 로그인한 학생의 글
- 글 제출 또는 수정 동작

학생이 아직 글을 제출하지 않았다면 글 입력 칸을 비워 둔다. 학생이 제출한 글이 있으면 저장된 글을 입력 칸에 보여 준다.

- 마감 전에는 글을 제출하거나 수정할 수 있다.
- 마감 후에는 새 제출과 수정을 할 수 없다.
- 글의 길이는 제한하지 않는다.

### 5.7 학생 피드백 확인 화면

로그인한 학생의 과제에서 다음 정보를 보여 준다.

- 자기 글
- 선생님 피드백

아직 선생님 피드백이 저장되지 않았다면 피드백이 아직 없다는 상태를 보여 준다. 다른 학생의 글이나 피드백은 이 화면에 표시하지 않는다.

## 6. 주요 사용자 흐름

### 6.1 선생님이 과제를 만들고 피드백하는 흐름

1. 선생님이 아이디와 비밀번호를 입력해 로그인한다.
2. 과제 목록에서 새 과제 만들기 또는 이전 과제 다시 사용하기를 선택한다.
3. 제목·설명·마감일을 정하고 과제를 저장한다.
4. 과제 목록에서 제출 인원·미피드백 글 수·마감일을 확인한다.
5. 과제를 열고 학생의 미피드백 글을 선택한다.
6. 학생 이름·글·제출 시간을 확인한다.
7. 피드백을 입력하고 저장한다.
8. 저장 결과가 학생의 피드백 확인 화면과 선생님 과제 목록의 미피드백 글 수에 반영된다.

### 6.2 학생이 글을 제출하고 피드백을 확인하는 흐름

1. 학생이 아이디와 비밀번호를 입력해 로그인한다.
2. 자기 과제 목록에서 과제를 선택한다.
3. 과제 제목·설명·마감일을 확인한다.
4. 자기 글을 입력해 제출한다.
5. 마감 전에는 같은 과제를 다시 열어 자기 글을 수정할 수 있다.
6. 선생님이 피드백을 저장한 뒤 자기 과제를 열어 자기 글과 피드백을 확인한다.

## 7. 데이터 및 저장

모든 데이터는 브라우저 `localStorage`에 저장하며, 새로고침 후에도 저장된 과제·제출 글·피드백을 다시 보여 준다.

### 사용자 데이터

- 사용자 아이디
- 비밀번호
- 역할: `teacher` 또는 `student`
- 학생 또는 선생님 화면에 표시할 이름

### 과제 데이터

- 과제 식별자
- 제목
- 설명
- 마감일
- 생성 시간

### 제출 및 피드백 데이터

- 제출 식별자
- 과제 식별자
- 학생 식별자
- 제출 글
- 최초 제출 시간
- 마지막 수정 시간
- 선생님 피드백
- 피드백 저장 시간

피드백이 저장되지 않은 제출은 미피드백 상태로 취급한다. 학생 제출 글과 피드백은 과제 식별자와 학생 식별자로 연결한다.

## 8. 권한 및 상태 규칙

- 로그인하지 않은 상태에서는 과제·제출 글·피드백 화면을 보여 주지 않는다.
- 학생 화면의 목록과 상세 내용은 현재 로그인한 학생의 데이터로만 제한한다.
- 선생님 화면에서는 모든 학생의 제출 글과 피드백을 볼 수 있다.
- 마감일이 지난 과제는 학생의 제출과 수정을 받지 않는다.
- 마감일은 과제별로 저장하고 표시한다.
- 선생님 피드백 저장 전 제출은 미피드백 글로 집계한다.
- 선생님 피드백 저장 후 제출은 피드백 완료 글로 집계한다.

## 9. 제외 범위

다음 기능은 구현하지 않는다.

- 학생이 다른 학생의 글이나 피드백을 보는 화면
- 다른 학생의 기록을 모아 보는 학생 화면
- 이메일·문자 등 별도 알림
- 학생 글의 최소 글자 수 제한
- 학생의 이모지 반응이나 답글 기능
- 선생님이 학생의 피드백 읽음 여부를 확인하는 기능
- 점수·등급을 매기는 기능
- 학부모 화면
- 실시간 채팅 기능
- 데이터베이스 또는 서버 저장
- 여러 HTML 파일로 나눈 화면

## 10. 수동 확인 기준

자동화 테스트 없이 브라우저에서 다음 장면을 직접 확인한다.

1. 선생님 계정으로 로그인했을 때 과제 목록과 제출 인원·미피드백 글 수·마감일이 보인다.
2. 새 과제를 만들거나 이전 과제를 다시 사용해 저장하면 과제 목록에 나타난다.
3. 학생 계정으로 로그인했을 때 자기 과제와 자기 글만 보인다.
4. 학생이 마감 전 글을 제출하고 다시 열었을 때 저장된 글을 수정할 수 있다.
5. 선생님 화면에서 학생 이름·글·제출 시간·피드백 입력 칸이 보이고, 피드백 저장 후 미피드백 글 수가 줄어든다.
6. 학생 화면에서 선생님이 저장한 피드백과 자기 글을 확인할 수 있다.
7. 브라우저를 새로고침해도 `localStorage`에 저장한 내용이 유지된다.
